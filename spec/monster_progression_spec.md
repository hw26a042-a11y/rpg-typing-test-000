# モンスター出現・難易度設計仕様書

## 1. 概要
本仕様書は、ゲーム中の「難易度のエスカレーション（徐々に難しくなる仕様）」および「出現モンスターのパラメータ」を定義します。
プレイヤーがタイピングを続けることで、自分が成長しボスを倒せるようになる「上達の達成感」を感じられるよう設計します。

## 2. 進行ステージと難易度設計（60秒完全固定）
ゲームはプレイヤーがモンスターを倒すたびに、次のモンスターが即座に登場する勝ち抜き方式です。
討伐数が増えるにつれてモンスターは強力（HP増加、お題テキストの長文化・難読化）になり、色違いの強化版が出現するようになります。

### 制限時間とペナルティのルール
*   **60秒完全固定**: 制限時間は1プレイにつき「完全に60秒間（1分間）」固定です。モンスターを討伐したりコンボを繋げたりしても、時間の増加や減少などの変動は一切発生しません。
*   **タイピングミスによるストップ（ペナルティ）**: タイピングミス（誤入力）をした際、**正しいキーが入力されるまで次の文字に進まずにその場で入力がストップ（ホールド）**します。ミス入力自体によって制限時間が直接引かれるようなシステムペナルティはありませんが、正しいキーを打ち直す必要があります。
*   **ミスの評価**: 誤入力の履歴はゲーム終了後の「不正解率（ミス率）」として記録・表示されます。

### モンスターのHPと出現お題の進行（難易度テーブル）
モンスターが出現すると、モンスターのHPと同じ回数だけ**「通常お題」**をタイピングすることで討伐（撃破）できます。

| 出現段階 | モンスター名 | モンスター特徴・色 | HP (必要お題数) | 通常お題の特徴（文字数） |
| :--- | :--- | :--- | :--- | :--- |
| **Lv.1** | **ブルースライム** | 最初の敵。最弱。 | **1** | 2〜3文字の超簡単な単語 |
| **Lv.2** | **ゴブリン** | すばやい雑魚敵。 | **1** | 4〜6文字の単語・短文 |
| **Lv.3** | **レッドスライム** | スライムの赤色強化版。 | **2** | 3〜5文字の少し長い単語 |
| **Lv.4** | **オーク** | 緑色の力強い中ボス。 | **2** | 7〜10文字の短い文章 |
| **Lv.5** | **レッドオーク** | 赤色の狂暴なオーク。 | **3** | 8〜11文字の文章 |
| **Lv.6** | **ドラゴン** | 強力な準ボス。紅蓮の竜。 | **3** | 11〜15文字のやや長めの文章 |
| **Lv.7** | **魔王（ボス）** | 最終ボス。闇の支配者。 | **5** | 16文字以上の長文・難読文 |
| **Lv.8〜** | **裏ボス・メタルスライム等** | 魔王を超える強敵、および超強化モンスターのループ。 | **5〜** | 16文字以上の超長文、難読文、特殊文 |

*※魔王撃破後は、さらに強力な裏ボスや、極めて強力になった「メタルスライム（HPは多いが、お題は極めて短く超高速タイピングが必要）」などの特殊なモンスターが制限時間終了まで無限に出現し続けます。*

## 4. 上達実感・練習効果の演出
プレイヤーに「練習し続けた結果、ボスまで倒せるようになった！」と感じてもらうための仕様。

1.  **自己ベストの記録**:
    *   結果画面で「過去の最高討伐モンスター」を保存・表示。
    *   例：「前回の記録：オーク ➔ 今回の記録：ドラゴン（成長！）」
2.  **リトライのしやすさ**:
    *   結果画面から1キーまたは1タップで即座に「再挑戦（リトライ）」できるように設計し、練習の反復を促します。
3.  **攻撃エフェクト・ヒット感**:
    *   タイピングするたびに剣の風切り音やモンスターへのダメージ演出を発生させ、タイピング行為そのものの爽快感を高めます。
