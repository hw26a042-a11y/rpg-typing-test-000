# タイピングRPGゲーム 仕様書

## 1. 概要
本仕様書は、ファンタジー世界を舞台にした、制限時間1分間の「タイピングRPGゲーム」の基本仕様を定義するものです。
プレイヤーはタイピングを成功させることでモンスターに攻撃し、制限時間内にどれだけ多くの敵（スライムからボスまで）を倒せるかを競います。

## 2. 基本情報
*   **ゲームタイトル**: タイピングファンタジー（仮）
*   **ジャンル**: タイピングRPG / バトルアクション
*   **世界観**: 王道ファンタジー（スライム、ゴブリン、ドラゴン、魔王などのモンスターが登場）
*   **対応プラットフォーム**: Webブラウザ（PC推奨、キーボード入力必須）

## 3. コアルールとゲームサイクル
1.  **バトル開始**: 制限時間「60秒（1分間）」のカウントダウンが始まります。この制限時間は完全固定であり、どのような要因でも増減しません。
2.  **モンスターのHPと討伐**: 
    *   モンスターには「HP（設定されたお題のクリア必要数）」が存在します。
    *   モンスターごとのHP（例：スライムは1、中盤モンスターは3、ボスは5など）に等しい回数だけ、お題テキストを完全に正しく入力し終えることで、そのモンスターを「討伐（撃破）」できます。
    *   討伐すると、次のモンスターが即座に出現（再びお題タイピングからスタート）します。
3.  **ミス時のストップ仕様（ペナルティの代替）**: 
    *   タイピング中にミス（間違ったキーの入力）をした場合、**正しいキーが入力されるまで次の文字に進まずにその場で入力がストップ（ホールド）**します。
    *   タイピングミスをしても、制限時間の減少などのゲーム進行を著しく妨げるペナルティはありませんが、正しいキーを打ち直す必要があります。
4.  **段階的な難易度上昇**:
    *   最初は「スライム」などの非常に簡単で短い文章からスタートします。
    *   討伐を繰り返すことで、モンスターの強さ（HP、お題の文字数・文章の複雑さ）が段階的に上がっていきます。
    *   通常色のモンスターを討伐し続けると、難易度が上がった「色違いのモンスター（例：赤いスライム、赤いオークなど）」が出現し、さらにその先には強力な「ボス（魔王など）」が出現します。
    *   ボスを倒した後は、さらに強力な裏ボスや、極めて強力になったスライム（例：メタルのスライムや超強化スライムなど）が出現するエンドレスループに突入します。
6.  **ゲーム終了（タイムアップ）**: 60秒が経過するとゲーム終了となり、結果画面（リザルト）へ遷移します。

## 4. スコア・評価システム
ゲーム終了時に、以下の実績と数値を集計して表示します。

*   **討伐実績**: 「〇〇（モンスター名）まで倒せた！」というプレイヤーの到達度の表示。
*   **入力成功キー数**: ゲーム中に正しく入力できた累計のキー入力数（キー押下数）。
*   **入力失敗キー数**: ゲーム中に間違えて入力してしまった累計のキー入力数（ミスタイプ数）。
*   **正答率（正確性）**: 
    *   計算式: `(入力成功キー数 / 総入力キー数) × 100 (%)`
*   **ミスタイプ率（不正解率）**: 
    *   計算式: `(入力失敗キー数 / 総入力キー数) × 100 (%)`
    *   ※総合スコアなどの複雑な指標は排除し、タイピングの純粋な量と精度を分かりやすく評価します。

## 5. 画面構成
*   **タイトル画面**
    *   ゲームタイトルロゴ
    *   「ゲームスタート」ボタン
    *   簡単な遊び方・ルールの説明（「1分間で迫りくるモンスターをタイピングで倒せ！」）
*   **バトル画面（プレイ画面）**
    *   **モンスター表示エリア**: 現在対峙しているモンスターのイラストやHPゲージ。
    *   **タイマー（制限時間表示）**: 残り時間をバーや数字（1秒単位）で大きく表示。
    *   **お題表示エリア**:
        *   お題となる日本語テキスト（例：「どうのつるぎ」）
        *   入力中のローマ字テキスト（例：「do**unoturugi**」：入力済みの文字と未入力の文字を色分け）
    *   **ステータス表示**: 現在の討伐数、入力成功キー数など。
*   **結果画面（リザルト画面）**
    *   「冒険終了！」のメッセージ
    *   **討伐結果**: 最大討伐モンスター名（例：「ドラゴンまで倒せた！」）
    *   **各種パラメータ表示**:
        *   入力成功キー数（Key）
        *   入力失敗キー数（Key）
        *   正答率（正確性）（％）
        *   ミスタイプ率（不正解率）（％）
    *   「もう一度挑戦する」ボタン
    *   「タイトルに戻る」ボタン
